CORE FEATURES
================================================================================

Template Management
  • Create unlimited reusable SOP templates
  • Organize by category, code, description
  • Define step-by-step instructions
  • Mark steps as critical (blocks workflow if not done)
  • Require evidence attachments for compliance
  • Optionally restrict templates to specific Odoo models
  • Duplicate templates for quick variations

Checklist Execution
  • One-click launch any template on a record (any Odoo model)
  • Template steps automatically copied to checklist instance
  • Real-time completion percentage & progress bar
  • Step counts (done / total)
  • Live checklist instance linked to record

Step Completion Tracking
  • Mark steps done individually with checkbox
  • Auto-records user and timestamp
  • Optional evidence attachment per step
  • Notes field for step-level comments
  • Critical step warning banner prevents premature completion
  • Can reopen or cancel checklists

Audit Trail & Compliance
  • Complete timestamp and user tracking per step
  • Evidence attachment management
  • Message thread for process communication
  • Workflow blocking on critical steps
  • Completion state management (in_progress, completed, cancelled)
  • Non-repudiation via immutable message thread

Integration
  • Works with any Odoo model (sales orders, projects, pickings, etc.)
  • Supports custom models
  • Mail module integration for notifications
  • Activity tracking with Chatter
  • Print-ready checklists

================================================================================
DATA MODELS
================================================================================

sop.template
  Main template model defining SOP structure.
  Fields: name, code, category, description, step_ids, step_count, 
          critical_step_count, active, applicable_models, checklist_count
  Methods: action_launch(), action_duplicate_template(), action_view_checklists(),
           get_applicable_models(), is_applicable_to_model()

sop.template.step
  Individual step in template.
  Fields: template_id, sequence, name, description, is_critical, 
          requires_evidence, responsible_role, estimated_minutes

sop.checklist
  Live checklist instance created from template.
  Fields: name, template_id, res_model, res_id, res_name, state, step_ids,
          completion_pct, steps_done, steps_total, critical_steps_pending,
          started_by_id, date_started, date_completed
  Methods: action_complete(), action_cancel(), action_reopen(),
           get_linked_record(), action_open_linked_record()

sop.checklist.step
  Individual step in a checklist instance tracking completion.
  Fields: checklist_id, sequence, name, description, is_critical,
          requires_evidence, done, done_by_id, done_date,
          evidence_attachment_id, notes
  Auto-behavior: When marked done, auto-sets done_by_id and done_date

sop.launch.checklist.wizard
  Transient wizard for launching templates on records.
  Fields: template_id, res_model, res_id, res_name, notes
  Methods: action_launch()

================================================================================
USAGE EXAMPLES
================================================================================

1. Create an Onboarding Template
   - SOP Checklist > Templates > Create
   - Name: "Employee Onboarding"
   - Code: "ONBOARD-01"
   - Add steps: documents, IT setup, office space, manager sign-off
   - Mark sign-off as Critical
   - Save

2. Launch Checklist on Contact
   - Open SOP Template "Employee Onboarding"
   - Click "Launch on Record"
   - Select contact and click "Launch Checklist"
   - New checklist instance created and opened

3. Complete Checklist
   - Review each step instruction
   - Check completion box for each step
   - System auto-records user and timestamp
   - Add notes or attach evidence as needed
   - When all critical steps done, click "Mark Complete"
   - State changes to Completed, date_completed set

4. View Analytics
   - SOP Checklist > Active Checklists
   - Filter by state, template, model
   - Group by template or state for analytics
   - Click checklist to see step-by-step details

SECURITY & COMPLIANCE
================================================================================

- All checklist data stored in Odoo database with standard security
- Access controlled via group-based access rules
- Evidence attachments follow Odoo's attachment security model
- Audit trail is immutable (state changes tracked, no deletion)

PERFORMANCE NOTES
================================================================================

- Tested with templates containing 100+ steps
- Checklist queries indexed on template_id and state for fast filtering
- Computed fields stored for performance (not recalculated every query)
- Message thread may grow large for long-running checklists—periodic cleanup recommended
- For large deployments, archive old checklists annually for database health

================================================================================
TROUBLESHOOTING
================================================================================

Q: Checklist won't mark complete
A: Review warning banner for pending critical steps. Check boxes to mark them done.

Q: Template not showing in launch wizard
A: Check "Applicable Models" field. Ensure model is in comma-separated list.

Q: Evidence attachment shows as required but allows completion
A: Current version is UI guideline. Implement custom validation if enforcement needed.

Q: Timestamp shows wrong user
A: System records user at the moment step is marked done. Ensure correct user logged in.

See README.md for detailed troubleshooting.
